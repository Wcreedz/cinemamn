Зурагнаас харахад таны `cinemamn` репозитори одоогоор **ямар ч файлгүй (хоосон)** байна. Тийм учраас GitHub дээр *"You must first add content to your repository"* буюу эхлээд контент/файл нэмэх шаардлагатай гэсэн анхааруулга гарч иржээ. Үүнийг засаад сайтынхаа линкийг идэвхжүүлэх маш энгийн алхмууд: ### 1. Файлаа нэмэх 1. Браузер дээрээ репозиторийнхоо үндсэн хуудас руу буцаад орно (**`[https://github.com/Rooden0327/cinemamn](https://github.com/Rooden0327/cinemamn)`**). 2. Гол хэсэгт байх **"get started by creating a new file"** (эсвэл **Add file** -> **Create new file**) гэсэн холбоос дээр дарна. 3. Файлын нэр бичих хэсэгт яг ингэж бичнэ: **`index.html`** 4. Доорх том зайнд доорх кодыг бүтнээр нь хуулж тавиад, хуудасны доод хэсэгт байх **"Commit changes..."** товчийг дарж хадгална. ### 2. Pages тохиргоогоо хадгалах 1. Файлаа хадгалсныхаа дараа буцаад **Settings -> Pages** хэсэг рүүгээ орно. 2. Одоо `None` гэж байсан хэсэг дээр дарж **`main`** гэдгийг сонгох боломжтой болсон байх болно. 3. **`main`**-ийг сонгоод баруун талд нь байрлах **Save** товчийг дарна.
