# Аюулгүй байдал

- **Нууц үг**: argon2id. **Refresh token**: зөвхөн SHA-256 hash, rotation, давтан ашиглалт илэрвэл гэр бүлээр нь цуцална.
- **Cookie**: HttpOnly, SameSite=Lax, production дээр Secure. Хэрэглэгч `mf_access`/`mf_refresh`, админ `mf_admin_access`/`mf_admin_refresh`: нэг хөтчид зэрэг ажиллана, `/api/admin` зөвхөн админ cookie-г уншина. `X-Auth-Scope: admin` толгой аль cookie-г унших л заана, эрх өгөхгүй. **CSRF**: SameSite + Origin allowlist.
- **Нэвтрэлт**: хэрэглэгч зөвхөн утсаар (`/login`), админ зөвхөн имэйлээр (`/admin/login`). Эрхийн ангилал хайлтын нөхцөлд орсон тул нөгөө замаар нэвтрэхгүй.
- **Эрх**: `requireAdmin` бүх `/api/admin`-д, хэрэглэгчийг хүсэлт бүрт баазаас уншина. Заавал биш IP allowlist.
- **Оролт**: Zod бүх endpoint-д, `$`/`.` түлхүүр хасна, regex-ийг escape хийнэ. **Файл**: зурагт magic byte, видеонд MIME/өргөтгөл + ffprobe.
- **Толгой**: Helmet, CORS allowlist, rate limit (IP), бүртгэлийн түгжээ.
- **Төлбөр**: фронтоос дүн авахгүй, callback-д дангаар итгэхгүй, нөхцөлт шинэчлэлт + unique индекс. Симулятор production-д холбогдохгүй.
- **Лог**: админы бүх үйлдэл `admin_logs`-д, нууц утгууд зөвхөн далдлагдсанаар.
- **Superadmin**: дээд тал нь 3, кодод нууц үг байхгүй, `npm run admin:bootstrap`. Богино нууц үгээр үүсгэвэл анхааруулга гарна: Профайл хэсгээс даруй солино.

## Анхаарах эрсдэл

- **Баталгаажуулалтгүй нууц үг солих:** `/forgot-password` дээр утасны дугаар мэдсэн хэн ч тухайн хэрэглэгчийн нууц үгийг сольж, бүртгэлд нь орж, хуучин сешнийг нь хааж чадна. Эзэмшлийг шалгах алхам (SMS код г.м.) нэмэх хүртэл хэрэглэгчийн бүртгэл хамгаалагдаагүй. Админ бүртгэлд хамаарахгүй.
- Утасны дугаар баталгаажуулдаггүй (SMS ашиглахгүй шийдвэр): хүн өөр хүний дугаараар бүртгүүлж болно.

- `quickqpaypackv2`-ийн эх кодод QPay-н нэвтрэх мэдээлэл бичигдсэн. Үүнд хандах эрхтэй хүн бүр (git, хувийн registry) уг мэдээллийг харж чадна.
- Хувийн registry шифрлэгдээгүй HTTP-ээр холбогддог. `package-lock.json`-ийн integrity hash нь татсан файлын бүрэн бүтэн байдлыг шалгана.
- Mongoose 6 багцын нийцлийн улмаас сонгогдсон: дэмжлэгийн хугацааг хянах хэрэгтэй.
