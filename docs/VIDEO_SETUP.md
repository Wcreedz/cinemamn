# Видео

```
/srv/mongolflix/{hls/<киноны id>/{master.m3u8,720p/...},posters,backdrops,temp}
```

Урсгал: админ байршуулна → `temp/` → `video_jobs` дараалал → worker FFmpeg → манифест шалгана → `hls/` руу зөөнө → төлөв `ready` → эх файлыг устгана. Төлөвүүд: `uploading → queued → processing → ready | failed`.

Шалгах: `video-server/scripts/check-ffmpeg.sh`. FFmpeg алга бол байршуулалт эхлэхгүй, админы Видео тохиргоонд анхааруулга гарна.

Серверийн асуудлаас (FFmpeg алга, диск дүүрсэн, бичих эрхгүй) болж амжилтгүй бол эх файл хадгалагдаж, киноны хуудсанд **Дахин боловсруулах** товч гарна. Файл эвдэрсэн бол устгаж, дахин байршуулахыг хүснэ.

Амжилттай боловсруулсан киноны эх файл серверт хадгалагдахгүй: чанарын тохиргоог өөрчилж дахин боловсруулах бол эх файлыг дахин байршуулна. Иймд эх файлаа серверээс өөр газар хадгална уу. Өмнөх хувилбарын `originals/` хавтсыг гараар устгаж болно.

## Хамгаалалт

- `POST /api/stream/:id/token`: нэвтрэлт, идэвхтэй эрх, нийтлэгдсэн кино шалгаад, тухайн кинонд холбогдсон хугацаатай токен өгнө (хугацаа админаас).
- Манифест, сегмент бүрд `auth_request` токен, кино, сешн, хэрэглэгчийн төлөв, эрхийг дахин шалгана. Nginx шийдвэрийг 15 секунд кэшилдэг тул эрх дууссанаас хойш хамгийн ихдээ 15 секунд тоглож болно.
- Боловсруулж буй эх файл (`temp/`) ямар ч URL-аар гарахгүй.

## Бодит хязгаарлалт

Энэ хамгаалалт зөвхөн эрхгүй татахаас сэргийлнэ. Эрхтэй хэрэглэгч дэлгэцээ бичих, хүчинтэй токенийг хугацаа дуустал хуваалцах боломжтой. Үүнийг бүрэн хаах бол DRM (Widevine/FairPlay) шаардлагатай ба одоогоор хийгдээгүй.

Токен URL-д байдаг тул Nginx-ийн access log энэ замд унтраалттай.
