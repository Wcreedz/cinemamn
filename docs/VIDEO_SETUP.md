# Видео

```
/srv/mongolflix/{originals,hls/<киноны id>/{master.m3u8,720p/...},posters,backdrops,temp}
```

Урсгал: админ байршуулна → `temp/` → `video_jobs` дараалал → worker FFmpeg → манифест шалгана → `hls/` руу зөөнө → төлөв `ready`. Төлөвүүд: `uploading → queued → processing → ready | failed`.

## Хамгаалалт

- `POST /api/stream/:id/token`: нэвтрэлт, идэвхтэй эрх, нийтлэгдсэн кино шалгаад, тухайн кинонд холбогдсон хугацаатай токен өгнө (хугацаа админаас).
- Манифест, сегмент бүрд `auth_request` токен, кино, сешн, хэрэглэгчийн төлөв, эрхийг дахин шалгана. Nginx шийдвэрийг 15 секунд кэшилдэг тул эрх дууссанаас хойш хамгийн ихдээ 15 секунд тоглож болно.
- Эх файл (`originals/`) ямар ч URL-аар гарахгүй.

## Бодит хязгаарлалт

Энэ хамгаалалт зөвхөн эрхгүй татахаас сэргийлнэ. Эрхтэй хэрэглэгч дэлгэцээ бичих, хүчинтэй токенийг хугацаа дуустал хуваалцах боломжтой. Үүнийг бүрэн хаах бол DRM (Widevine/FairPlay) шаардлагатай ба одоогоор хийгдээгүй.

Токен URL-д байдаг тул Nginx-ийн access log энэ замд унтраалттай.
