# QPay тохиргоо

QPay-н бүх дуудлага [quickqpaypackv2](../backend/src/services/qpay.gateway.ts) сангаар явна. Санг өөрчилдөггүй.

## Тохируулах

1. `.env`-д `QPAY_MERCHANT_SERVER` (төгсгөлд `/`-тэй).
2. `/admin/settings` → **QPay тохиргоо**: байгууллага, салбар, (заавал биш) данс, callback URL.
3. Харилцагч байхгүй бол мөн хуудасны **QPay харилцагч** хэсгээс бүртгэнэ (`qpayKhariltsagchUusgey`, Superadmin). Өөр баазад бүртгэлтэй бол `QPAY_MONGODB_URI`-г заана.
4. **Харилцагч шалгах**, **Холболт шалгах**, дараа нь идэвхжүүлж хадгална. Идэвхжүүлэх үед хоёр шалгалт автоматаар ажиллах ба алдаатай бол хадгалахгүй.

## Сангаас үүдэх хязгаарлалт

| Хязгаарлалт | Үр дагавар |
|---|---|
| Нэвтрэх мэдээлэл санд кодоор бичигдсэн | Админаас Client ID/Secret оруулах талбар байхгүй. `QPayConfiguration` шифрлэсэн нэвтрэх мэдээлэл хадгалдаггүй |
| Сервер нэг `QPAY_MERCHANT_SERVER`-ээс уншина | Орчныг вэбээс солих боломжгүй: админ тохиргооны орчин серверийнхтэй таарахгүй бол идэвхжихгүй |
| Валют `MNT` бичигдсэн | MNT-ээс өөр үнийн нэхэмжлэх үүсгэхгүй |
| Хувилбар нь нэвтрэх мэдээллийг бус лавлагааг хамардаг | Сан доторх нэвтрэх мэдээлэл солигдвол хуучин нэхэмжлэхүүд шинэ мэдээллээр шалгагдана |
| `qpayShalgay` салбар=шимтгэлтэй, данс=шимтгэлгүй үед өөр эрхээр шалгадаг | Энэ хослолыг "Харилцагч шалгах" хориглоно |

## Шалгалтын логик

`payment/check`-ийн хариуг `parseCheckResponse` уншина. Албан ёсны баримтад талбарын нэрс бүрэн тодорхойгүй тул тест сервер дээр шалгасан. Бодит sandbox дээр туршаад шаардлагатай бол энэ функцийг тааруулна. Хариунд төлсөн дүн олдохгүй бол (`unverifiable`) эрхийг автоматаар идэвхжүүлэхгүй, админ "Төлбөрүүд" хэсгээс шалгана.

QPay-н баримт `payment/check`-ийг cron-оор дуудахыг хориглодог тул callback, хэрэглэгчийн товч (10 секундийн cooldown), админы товчоор л дуудна.

## Callback

`GET|POST /api/payments/qpay/callback?order=<захиалга>`. Хүсэлтийн агуулгад итгэхгүй, зөвхөн QPay-с шууд шалгасан үр дүнг ашиглана. Callback PAID төлөвөөс түрүүлж ирэх тохиолдолд богино завсартай дахин шалгана (`QPAY_CHECK_RETRIES`).
